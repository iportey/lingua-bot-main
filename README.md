# 🎓 LinguaTutor — интерактивный тренажер английского языка для ВКонтакте

**LinguaTutor** — это автономный образовательный чат-бот, предназначенный для изучения иностранных слов и проверки знаний в формате увлекательной игры. Проект полностью работает на локальных данных, что гарантирует мгновенный отклик и нулевую зависимость от сторонних сервисов.

## 🚀 Ключевые возможности

- **Умные карточки слов**: Изучение лексики по тематическим блокам (Еда, Путешествия, Бизнес). Для каждого слова доступна транскрипция и перевод, которые открываются по клику.
- **Мини-квизы с геймификацией**: Проверка знаний в формате тестов с тремя уровнями сложности (Легкий, Средний, Сложный).
- **Система мотивации**: За правильные ответы начисляются баллы (+10), за неправильные — списываются (-5).
- **Сохранение прогресса**: Бот запоминает успехи пользователя (количество очков и правильных ответов) в базе данных. Данные не сбрасываются при перезапуске бота.
- **Удобный интерфейс**: Полное управление реализовано через комбинацию Reply-кнопок (главное меню) и Inline-кнопок (выбор ответов, переворот карточек, темы).

## 🧠 Логика работы

Сценарий взаимодействия построен на основе конечного автомата (FSM), что исключает возникновение тупиковых ситуаций.

```text
/start
  │
  ├─► Приветствие + главное меню
  │
  ├─► [Карточки слов]
  │     ├─► Выбор темы (Еда / Путешествия / Бизнес) — inline
  │     └─► Показ слова + транскрипция (лицевая сторона)
  │           ├─► [Показать перевод] — inline (обратная сторона)
  │           └─► [Следующее слово] — inline
  │
  ├─► [Мини-квиз]
  │     ├─► Выбор сложности (Легкий / Средний / Сложный) — inline
  │     ├─► Вопрос + 3 варианта ответа — inline
  │     └─► Проверка ответа → Начисление/списание баллов → Следующий вопрос
  │
  ├─► [Мой прогресс] ──► Вывод текущего счета и статистики из БД
  │
  └─► [Помощь]       ──► Справка по функционалу

Любой нераспознанный ввод → возврат в главное меню с подсказкой.

```

⚙️ Техническая архитектура
Проект спроектирован с применением принципов чистой архитектуры, где каждый слой изолирован и отвечает за свою задачу:

text
app/
├── bot/ # Слой интеграции с VK API (handlers, keyboards, states)
├── db/ # Работа с базой данных (SQLAlchemy 2.0, aiosqlite)
├── domain/ # Бизнес-логика бота (сценарий, тексты, база знаний)
│ ├── content.py # Хранилище карточек и вопросов квиза (статичные данные)
│ ├── scenario.py # (опционально) логика обработки, если вынесена
│ └── texts.py # Все текстовые сообщения бота
├── services/ # Вспомогательные сервисы (валидаторы)
├── config.py # Загрузка переменных окружения из .env
└── main.py # Точка входа, настройка логирования, запуск Long Poll
Отсутствие внешних API — это осознанное архитектурное решение. База знаний (слова и вопросы) хранится в content.py. Это обеспечивает:

Мгновенную скорость ответа (нет задержек на сетевые запросы).

100% отказоустойчивость (бот продолжит работать даже при полном отключении внешнего интернета, кроме самого VK API).

Отсутствие лимитов на количество запросов к базе знаний.

🛠️ Быстрый старт
Требования
Python 3.11+

Сообщество ВКонтакте с включенными сообщениями и Long Poll API.

Пошаговая установка
Клонируйте репозиторий:

bash
git clone <URL*ВАШЕГО*РЕПОЗИТОРИЯ>
cd lingua-bot
Создайте виртуальное окружение и установите зависимости:

bash
python -m venv .venv
source .venv/bin/activate # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
Настройте переменные окружения:

bash
cp .env.example .env
Откройте .env и впишите ваш VK_TOKEN.

Запустите предварительную проверку:

bash
python smoke_test.py
Скрипт проверит создание базы данных, доступ к контенту и корректность логики.

Запустите бота:

bash
python -m app.main
Откройте сообщество ВК и отправьте боту команду /start.

📊 Ограничения и лимиты
Поскольку бот не использует внешние платные API, ограничения касаются только инфраструктуры ВКонтакте:

Лимиты Long Poll API: Стандартные ограничения для ботов.

Хранение данных: Используется локальная СУБД SQLite, которая не имеет ограничений на количество записей в рамках текущей задачи.
